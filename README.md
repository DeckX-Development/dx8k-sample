# DeckX Sample Templates (dx8k-sample)

Official developer sample templates for **DeckX Control Studio** and DeckX devices (.NET 8).

This repository contains ready-to-use template projects and developer guides for building plugins, canvas widgets, clock faces, and game overlays for DeckX.

---

## 📦 Included Templates

| Template | Description |
| :--- | :--- |
| [**DeckX.Plugin.SampleTemplate**](./DeckX.Plugin.SampleTemplate) | Standard button/macro plugin template demonstrating key actions, state toggles, and hardware integration. |
| [**DeckX.Plugin.CanvasSampleTemplate**](./DeckX.Plugin.CanvasSampleTemplate) | Full-canvas rendering plugin template for rich custom UI and continuous graphics updates. |
| [**DeckX.ClockFace.SampleTemplate**](./DeckX.ClockFace.SampleTemplate) | Custom clock face template for DeckX standby and clock modes. |
| [**DeckX.GameOverlay.SampleTemplate**](./DeckX.GameOverlay.SampleTemplate) | In-game HUD / telemetry overlay template for DeckX. |

---

## 🛠️ Prerequisites

- [.NET 8.0 SDK](https://dotnet.microsoft.com/download/dotnet/8.0) or later
- Visual Studio 2022 / VS Code / JetBrains Rider
- [DeckX Control Studio](https://github.com/Nactro-Development/DeckX-Control-Studio)

---

## 🚀 Getting Started

1. Clone this repository:
   ```bash
   git clone https://github.com/DeckX-Development/dx8k-sample.git
   ```
2. Navigate to the desired template folder:
   ```bash
   cd DeckX.Plugin.SampleTemplate
   ```
3. Check the template's `README.md` and included PDF developer guide for detailed build and setup instructions.
